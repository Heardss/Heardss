## About

Arch Linux user - using Linux for about a year now. Started with KDE Plasma, fell in love with Hyprland. First distro was Arch and I'm still using it. Love using Nvim with LazyVim by Folke Lemaitre. If I have to use Windows (I hope not), I use Tiny10 with ChrisTitusTech's WinUtil tool to disable all the telemetry.
